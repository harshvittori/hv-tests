# HV Vault Maturity Assessment

A scenario-based maturity test. Each attempt picks 28 to 30 real-life situations from a bank of 104, scores answers across 10 dimensions, and gives two personal PDFs: a full results report and a 30-day plan of action built from the person's own answers.

**Live:** https://harshvittori.github.io/maturity-assessment/

Everything runs in the browser. No login, no server, and no answers are stored or sent anywhere. The whole app is a single `index.html`. To update the site, replace `index.html` in this repo and GitHub Pages redeploys automatically.

This is a self-assessment and personal growth tool, not a clinical or psychological diagnosis.
