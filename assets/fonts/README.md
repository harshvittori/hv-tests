# Fonts

`Outfit-Bold.ttf` and `Outfit-SemiBold.ttf`: Outfit by Rodrigo Fuenzalida, licensed under the SIL Open Font License 1.1 (https://openfontlicense.org). Used for the HV TEST wordmark inside the PDFs; the web pages load the same font from Google Fonts.

Scorecard fonts (static instances made from the Google Fonts variable fonts, subset to Latin, Latin-1 and Latin Extended-A to keep PDFs small). All SIL Open Font License 1.1:
- `PlayfairDisplay-SemiBold.ttf`: Playfair Display by Claus Eggers Sørensen (weight 600). Name and score on the scorecard. See `OFL-PlayfairDisplay.txt`.
- `Outfit-Regular.ttf`: Outfit (weight 400). Body text on the scorecard.
- `JetBrainsMono-Medium.ttf`: JetBrains Mono by JetBrains (weight 500). The scorecard ID. See `OFL-JetBrainsMono.txt`.
