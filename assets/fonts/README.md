# Fonts

`Outfit-Bold.ttf` and `Outfit-SemiBold.ttf`: Outfit by Rodrigo Fuenzalida, licensed under the SIL Open Font License 1.1 (https://openfontlicense.org). Used for the HV TEST wordmark inside the PDFs; the web pages load the same font from Google Fonts.

Scorecard fonts (static instances made from the Google Fonts variable fonts, subset to Latin, Latin-1 and Latin Extended-A). SIL Open Font License 1.1:
- `Sora-Regular.ttf`, `Sora-SemiBold.ttf`: Sora by Jonathan Barnbrook and Julián Moncada (weights 400, 600). All scorecard text, name and score. See `OFL-Sora.txt`.
- `GeistMono-Medium.ttf`: Geist Mono by Vercel (weight 500). The scorecard ID. See `OFL-GeistMono.txt`.
The scorecard image also uses `Outfit-Bold.ttf` / `Outfit-SemiBold.ttf` for the HV TEST wordmark.
